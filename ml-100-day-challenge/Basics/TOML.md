### TOML stands for Tom's Obvious, Minimal Language.

---
##### INI file (short for "Initialization")
is a simple, plain-text configuration file format traditionally used by Windows operating systems and software to store user settings and program preferences.  
###### Structure of an INI File
An INI file organizes configurations using Sections, Keys, and Values:
```Ini, TOML
; Comments start with a semicolon

[ServerSettings]
Port = 8080
Host = localhost
MaxConnections = 100

[UserSettings]
Theme = dark
AutoSave = true
```
>[!NOTE]
>TOML replaced INI because INI was never standardized and lacked the capabilities needed for modern application configuration.

 Example:
 ```
uv pip compile pyproject.toml -o requirements.txt
```
Step-by-Step Example
##### 1. Input (pyproject.toml)
You define only the direct dependencies your project needs (without fixing exact versions):
```Ini, TOML
[project]
name = "my-app"
version = "0.1.0"
dependencies = [
    "requests",
]
```
#### 2. What the Command Does
When you run the compile command, uv (or pip-compile):
 - Looks up requests on PyPI to find its latest stable version (e.g., 2.31.0).
 - Checks all the dependencies that requests needs to run (sub-dependencies like urllib3, certifi, idna, charset-normalizer).
 - Determines exact, compatible versions for every single package so there are no version conflicts.
#### 3. Output (requirements.txt)
It automatically generates a fully locked requirements.txt file:
```
# This file was autogenerated by uv via the following command:
#    uv pip compile pyproject.toml -o requirements.txt
certifi==2024.2.2
    # via requests
charset-normalizer==3.3.2
    # via requests
idna==3.6
    # via requests
requests==2.31.0
    # via my-app
urllib3==2.2.1
    # via requests
```
